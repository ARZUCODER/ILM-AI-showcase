## What was done
- Firebase Authentication backend va frontendga ulandi. API endpointlar JWT token orqali himoyalandi.
- Document Ingestion Pipeline yozildi: Foydalanuvchi fayl yuklaydi -> Matn o'qiladi -> 900 belgidan iborat chunklarga bo'linadi.
- Gemini API (`text-embedding-004`) yordamida chunklar vektorlarga aylantirilib `pgvector`ga tushyapti. 
- Vektorlarni saqlash uchun birdaniga 50 ta chunkni jo'natadigan "Batch Embedding" mexanizmi yozildi.

## Problems encountered
- Go tilidagi standart PDF o'quvchi kutubxonalar o'zbek va rus tilidagi ba'zi belgilarni, jadvallarni va rasmli PDF larni umuman o'qiy olmadi.
- Birdaniga ko'p fayl yuklanganda Vertex API'dan "429 Too Many Requests" xatosi keldi.

## Solutions
- PDF larni o'qish uchun Gemini 2.5 Flash'ning o'ziga "Extract ALL the textual content" degan prompt bilan faylni yubordim. Natija 100% toza matn bo'ldi.
- API kvotasiga tushmaslik uchun "Exponential backoff" (kutib qayta urinish) algoritmini qo'shdim.
