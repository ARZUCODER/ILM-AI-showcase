# Date: June 7, 2026

## What was done
- Conducted the Human Evaluation Rubric on 50 RAG queries. Results show a hallucination rate of < 5% thanks to the strict distance threshold (0.6) and system prompts.
- Created the final Pitch Deck.
- Recorded the final "End-to-End User Journey" demonstration video.

## Problems encountered
- **Critical Cost Issue:** I wanted to use my Google Cloud startup credits to pay for API usage. However, Google AI Studio (raw Gemini API) has a completely separate billing system and does not accept Cloud credits.

## Solutions
- **Final Architecture Win:** I refactored my code to use **Firebase Vertex AI** for the frontend and **Cloud Vertex AI** (`cloud.google.com/go/vertexai`) for the backend. By routing requests through Vertex AI instead of AI Studio, I successfully linked my Google Cloud startup credits. Now, this LLM-heavy B2C application runs practically for free!
