# Date: May 18, 2026

## What was done
- Integrated Firebase Authentication on both backend and frontend. Wrote custom Auth Middleware in Go to verify JWT tokens.
- Built the Document Ingestion Pipeline: User uploads a file -> text is extracted -> split into ~900 character chunks.
- Used Gemini API (`text-embedding-004`) to convert chunks into vectors and stored them in `pgvector`.
- Implemented a "Batch Embedding" system to send 50 chunks per API call to avoid rate limits.

## Problems encountered
- Standard Go PDF parsing libraries completely failed to read documents with Cyrillic/Uzbek fonts or complex layouts.

## Solutions
- Instead of using standard parsers, I sent the raw file directly to the **Gemini 2.5 Flash** model with the prompt "Extract ALL the textual content". The result was 100% clean text!
