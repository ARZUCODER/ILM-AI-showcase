## What was done

- **Learning Plan:** Added an agent that generates a strict Day-by-Day study plan in JSON format based on the user's goal and deadline.
- **Telegram Bot:** Finished the bot logic for sending daily reminders and running quick quizzes.
- **Deployment:** Successfully deployed the Web App version. It is now live at: http://ilmai.arzucoder.uz/

## Problems encountered
- When prompting the LLM to return a JSON array for Flashcards and Plans, the model occasionally wrapped the response in Markdown backticks (```json ... ```). This broke the JSON parser in Dart.

## Solutions
- Added `responseMimeType: 'application/json'` to the API call. Also, wrote a custom Regex cleaner in Dart to strip out any leftover markdown artifacts before parsing the JSON.
