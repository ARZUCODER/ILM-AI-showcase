# Date: May 31, 2026

## What was done
- **Monetization:** Added Free and Premium tiers. Integrated local payment providers (Click and Payme) to generate direct checkout URLs from the backend.
- **Promocodes:** Built a dynamic promocode system managed via the Admin Panel. Users can enter a code to unlock Premium features.
- Applied quotas for Free tier users (max 3 files, 10 chat messages, 50 flashcards).
- Completed Multi-language support (UZ, RU, EN) using Riverpod's `LocaleNotifier`.

## Problems encountered
- Generating the Payme checkout URL required Base64 encoding, but the URL was breaking and rejecting payments.

## Solutions
- Fixed the Base64 encoding in Go using `base64.StdEncoding.EncodeToString`. Also, corrected the payment amounts since Payme requires the amount to be calculated in 'tiyins' (amount * 100).
