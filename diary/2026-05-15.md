# Date: May 15, 2026

## What was done
- Decided on the core architecture: **Golang (Gin framework)** for the backend and **Flutter (Riverpod)** for the cross-platform frontend.
- Set up the PostgreSQL database and installed the `pgvector` extension for vector storage.
- Created database schemas for users, source_files, and knowledge_chunks.
- Started building the initial UI shell in Flutter using a custom "Liquid Glass" design language.

## Problems encountered
- When running the backend and database together using Docker Compose, the Go application kept throwing a "Connection refused" error because it was trying to connect before PostgreSQL was fully initialized.

## Solutions
- Implemented a "Retry mechanism" in Go's database connection logic. It now waits 2 seconds and retries up to 10 times until the database is ready. This completely solved the startup race condition.
